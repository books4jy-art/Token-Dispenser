📱 토스뱅크 입금 알림 연결 방법

이 안내대로 하면 토스뱅크 통장에 입금이 들어올 때 그 알림이 디스코드 봇에 자동으로 전달되고, 봇이 입금한 사람의 잔액을 알아서 충전해 줘요. 처음 해 보셔도 괜찮아요. 천천히 순서대로 따라 하시면 돼요.

⏱ 약 10분 · 안드로이드 폰 · 무료
시작하기 전에 알아 두세요
  • 안드로이드 폰에서만 할 수 있어요. (아이폰은 안 돼요)
  • 이 폰에 토스 앱이 설치되어 있고 로그인되어 있어야 해요. (토스뱅크 통장 알림은 토스 앱으로 와요)
  • 관리자에게 "연결 주소"를 따로 받아 두세요. (4단계에서 붙여넣어요)
🔒 무엇이 전달되나요? 봇에게는 토스 앱의 알림 내용만 전달돼요. 봇은 그중 입금 알림(예: "홍길동님이 10,000원을 보냈어요")만 사용하고, 결제·광고 같은 다른 알림은 저장하지 않고 바로 버려요. 다른 앱 알림, 문자, 사진, 계좌 비밀번호·로그인 정보는 절대 전달되지 않아요. MacroDroid에서 매크로를 끄면 언제든 바로 멈춰요.

0토스 입금 알림 켜기

  1. 폰의 설정 → 애플리케이션 → 토스 → 알림 에서 알림이 켜짐인지 확인해요.
  2. 토스 앱 안에서도 전체 → 설정 → 알림 에서 토스뱅크 입출금 알림이 켜져 있는지 확인해요.
✅ 입금되면 폰 위쪽에 "○○○님이 10,000원을 보냈어요" 같은 알림이 뜨면 준비 완료!

1MacroDroid 앱 설치

  1. Play 스토어를 열고 검색창에 MacroDroid 를 입력해요.
  2. 로봇 모양 아이콘의 "MacroDroid - 기기 자동화" 를 설치 해요. (무료)
  3. 앱을 열면 소개 화면이 나와요. 건너뛰기 또는 다음 으로 넘어가요.
💡 유료 버전(Pro) 안내가 나와도 그냥 닫으세요. 무료 버전으로 충분해요.

2새 매크로 만들기

  1. 첫 화면에서 매크로 추가 (Add Macro) 를 눌러요.
  2. 위쪽 매크로 이름 칸에 입금 알림 전달 이라고 적어요.
✅ 화면에 빨간색 '트리거', 파란색 '동작', 초록색 '제약 조건' 칸이 보이면 성공!

3트리거 설정 "토스 알림이 오면"

  1. 빨간색 트리거 칸 오른쪽의 ＋ 를 눌러요.
  2. 위쪽 돋보기(🔍)를 눌러 알림 이라고 검색 → 알림 (Notification) 을 눌러요.
  3. 알림 수신 (Notification Received) 을 고르고 확인.
  4. "알림 접근 권한이 필요해요" 창이 뜨면 확인 → 설정 화면에서 MacroDroid 스위치를 켜고 → 뒤로 가기로 돌아와요.
  5. 앱 선택 을 고르고 목록에서 토스 를 체크 → 확인.
    (목록에 '토스뱅크' 앱이 따로 있으면 그것도 함께 체크해요)
  6. 텍스트 내용은 모두 (Any) 를 고르고 확인.
✅ 빨간 트리거 칸에 '알림 수신 (토스)' 가 보이면 성공!
⚠️ 토스·토스뱅크 말고 다른 앱(카카오톡 등)은 절대 체크하지 마세요.

4동작 설정 "알림 내용을 봇에게 보내기"

  1. 파란색 동작 칸 오른쪽의 ＋ 를 눌러요.
  2. 위쪽 돋보기(🔍)를 눌러 HTTP 라고 검색 → HTTP 요청 (HTTP Request) 을 눌러요.
  3. 설정 화면에서 아래 3가지를 채워요.
① 요청 방법POST 를 골라요. (Request Method)
② URL관리자가 보내 준 연결 주소를 길게 눌러 복사 → URL 칸을 길게 눌러 붙여넣기.
한 글자도 빠지면 안 돼요. 주소는 이렇게 생겼어요:
https://○○○.duckdns.org/deposit?token=…
③ 본문 내용아래쪽 콘텐츠 본문 (Content Body) 에서
• 콘텐츠 유형: text/plain
• 본문 칸에 아래 글자를 대괄호까지 똑같이 적어요:
[notification_title] [notification]
💡 적기 어려우면 본문 칸 옆의 … 버튼을 눌러 '알림 제목' 과 '알림 텍스트' 를 차례로 넣어도 똑같아요.
  1. 오른쪽 위 ✓ 또는 확인 을 눌러요.
✅ 파란 동작 칸에 'HTTP 요청 (POST)' 가 보이면 성공!

5저장하기

  1. 저장 버튼(✓ 또는 💾 디스크 모양)을 눌러요.
  2. 매크로 목록에 '입금 알림 전달' 이 생기고 스위치가 켜져 있는지 확인해요.

6연결 테스트

  1. 매크로 목록에서 '입금 알림 전달' 을 길게 눌러요. (또는 매크로를 열고 오른쪽 위 ⋮)
  2. 테스트 매크로 (Test Macro / 동작 테스트) 를 눌러요.
  3. 관리자에게 "테스트 눌렀어요" 라고 알려 주세요.
✅ 관리자 쪽 디스코드에 "📱 입금 알림 폰 연결 확인" 이 뜨면 연결 성공이에요!

7꺼지지 않게 설정 아주 중요해요!

폰이 배터리를 아끼려고 MacroDroid를 몰래 끄면 알림이 전달되지 않아요.

  1. 폰 설정 → 애플리케이션 → MacroDroid
  2. 배터리 → 제한 없음 (또는 '최적화 안 함') 으로 바꿔요.
  3. 삼성 폰이라면: 설정 → 배터리 → 백그라운드 사용 한도 에서 '사용하지 않는 앱을 절전 상태로 전환'을 끄거나, 절전 예외 앱에 MacroDroid를 추가해요.
💡 최근 앱 목록에서 MacroDroid 화면을 닫아도 괜찮아요. 매크로는 계속 일해요.

✓마지막 확인

  • 토스 앱의 토스뱅크 입출금 알림이 켜져 있다
  • 매크로 '입금 알림 전달' 스위치가 켜져 있다
  • 트리거에 토스(와 토스뱅크)만 선택되어 있다
  • 테스트 후 관리자가 "연결 확인"을 받았다
  • MacroDroid 배터리 설정이 '제한 없음'이다
평소에 지켜 주세요
  • 폰은 켜져 있고 와이파이나 데이터가 연결되어 있어야 해요.
  • 토스 앱에서 로그아웃하거나 알림을 끄면 안 돼요.
  • 폰을 바꾸거나 초기화하면 이 설정을 다시 해야 해요.
잘 안 될 때
  • 테스트했는데 연결 확인이 안 와요 → URL을 정확히 붙여넣었는지(앞뒤 공백 없이), 인터넷이 켜져 있는지 확인해요.
  • 입금했는데 자동 충전이 안 돼요 → 0단계(알림 켜기)와 7단계(배터리)를 다시 확인하고 관리자에게 알려 주세요. 관리자가 직접 충전해 줄 수 있어요.
  • 메뉴 이름이 달라요 → 폰 기종이나 앱 버전마다 조금 달라요. 비슷한 이름을 찾거나, 화면을 캡처해서 관리자에게 보내 주세요.
🔒 보안 — 꼭 지켜 주세요 관리자가 보내 준 연결 주소에는 비밀번호가 들어 있어요. 다른 사람에게 보내거나, 단체 대화방·SNS에 올리지 마세요.
