🔗 입금 알림 주소 바꾸는 방법

입금했는데 디스코드에서 자동으로 충전되지 않을 때, 폰(MacroDroid)에 넣어 둔 연결 주소를 새로 바꿔 주면 돼요. 코드나 컴퓨터를 몰라도 괜찮아요. 복사해서 붙여넣기만 하면 돼요.

⏱ 약 5분 · 앱 새로 설치 안 해도 돼요
누가 무엇을 하나요?
  • 1부 — 관리자 (디스코드): 새 연결 주소를 받아서 계좌 주인에게 보내요.
  • 2부 — 계좌 주인 (안드로이드 폰): MacroDroid에 있는 주소를 새 주소로 바꿔요.
관리자와 계좌 주인이 같은 사람이면 둘 다 직접 하시면 돼요.
1부 · 관리자 디스코드에서

1 새 연결 주소 받기

  1. 디스코드에서 봇이 있는 원래 서버(입금이 자동 충전되는 서버)로 가요.
  2. 채팅 칸에 /입금 폰설정 이라고 입력하고, 위에 뜨는 목록에서 /입금 폰설정을 눌러 보내요.
  3. 나만 보이는 메시지가 와요. 아래쪽 🔗 연결 주소의 회색 칸에 있는 주소가 새 주소예요.
✅ 주소는 https://shopbotbc.duckdns.org/deposit?token= 으로 시작하는 긴 한 줄이에요.

2 주소 복사해서 보내기

  1. PC: 회색 칸 오른쪽 위의 복사 아이콘을 눌러요.
    폰: 회색 칸을 길게 눌러 복사를 눌러요.
  2. 카카오톡 같은 메신저에서 계좌 주인과의 1:1 대화방을 열고 붙여넣어 보내요.
  3. 이 안내서(PDF)도 함께 보내 주세요.
🔒 꼭 지켜 주세요이 주소에는 비밀번호가 들어 있어요. 계좌 주인에게만 보내고, 단체방·SNS에는 절대 올리지 마세요. 주소가 새면 누구나 가짜 입금을 만들 수 있어요.
2부 · 계좌 주인 안드로이드 폰에서

3 받은 주소 복사하기

  1. 관리자가 보내 준 메시지(주소)를 길게 눌러요.
  2. 복사를 눌러요.
⚠️ 주소의 일부분만 복사되면 안 돼요. 메시지 전체를 복사해 주세요.

4 MacroDroid에서 매크로 열기

  1. 로봇 모양 아이콘의 MacroDroid 앱을 열어요.
  2. 아래쪽 매크로 (Macros) 를 눌러요.
  3. 목록에서 '입금 알림 전달' 매크로를 눌러서 열어요. (이름을 다르게 지었다면 HTTP 요청이 들어 있는 매크로예요)
✅ 빨간 트리거, 파란 동작 칸이 보이면 맞게 연 거예요.

5 주소 바꿔 넣기

  1. 파란색 동작 칸에 있는 HTTP 요청 (POST) 를 눌러요. 메뉴가 뜨면 구성 또는 설정 (Configure) 을 눌러요.
  2. URL 칸에 있는 예전 주소를 전부 지워요.
    칸을 길게 눌러 '모두 선택' → 지우기(⌫). 칸이 완전히 비었는지 확인해요.
  3. 빈 URL 칸을 길게 눌러 붙여넣기를 눌러요.
  4. 다른 칸(요청 방법 POST, 본문)은 건드리지 마세요. 주소만 바꾸면 돼요.
  5. 오른쪽 위 ✓ 또는 확인을 눌러요.
맞는지 확인주소가 https:// 로 시작해요 맨 앞·맨 뒤에 빈칸이나 줄바꿈이 없어요 token= 뒤의 글자가 끝까지 다 있어요

6 저장하기

  1. 매크로 화면의 저장 버튼 ✓ 또는 💾 을 눌러요.
  2. 매크로 목록에서 '입금 알림 전달'의 스위치가 켜져 있는지 확인해요.

7 연결 테스트

  1. 매크로 목록에서 '입금 알림 전달'을 길게 눌러요. (또는 매크로를 열고 오른쪽 위 ⋮)
  2. 테스트 매크로 (Test Macro / 동작 테스트) 를 눌러요.
  3. 관리자에게 "테스트 눌렀어요" 라고 알려 주세요.
✅ 관리자 쪽 디스코드 로그 채널에 "📱 입금 알림 폰 연결 확인"이 뜨면 성공이에요! 마지막으로 1,000원을 실제로 충전해 보면 확실해요.
그래도 안 될 때
  • 테스트했는데 연결 확인이 안 와요 → 5단계를 다시 해 주세요. 주소가 잘렸거나 빈칸이 들어간 경우가 가장 많아요. 폰 인터넷(와이파이·데이터)이 켜져 있는지도 확인해요.
  • 테스트는 되는데 실제 입금이 충전 안 돼요 → 폰 설정 → 애플리케이션 → MacroDroid → 배터리 → 제한 없음으로 바꿔 주세요. 토스 앱 알림이 켜져 있는지도 확인해요.
  • 메뉴 이름이 달라요 → 폰 기종이나 앱 버전마다 조금 달라요. 비슷한 이름을 찾거나, 화면을 캡처해서 관리자에게 보내 주세요.
화면을 캡처해서 보낼 때 주소가 보이는 화면을 캡처하면 token= 뒤의 글자를 가리고 보내 주세요. 그 부분이 비밀번호예요.
