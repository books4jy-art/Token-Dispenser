# 자동 구매 봇 (자판기)

디스코드 서버용 자판기 봇이에요. 유저가 **계좌로 입금하면 자동으로 잔액(원)이 충전**되고,
그 잔액으로 서버의 상품·서비스를 24시간 자동으로 구매할 수 있어요. 가격과 잔액은 모두 원 단위예요.

## 기능

| 유저 | |
|---|---|
| `/충전` | 금액과 입금자명을 입력하면 계좌를 안내하고, 입금이 확인되면 자동 충전 + DM 알림 |
| `/상점` | 상품을 골라 잔액으로 구매 |
| `/키등록` | 평생 무료 키를 등록해 평생 무료 회원이 됨 |
| `/잔액` `/구매내역` `/랭킹` `/출석` | 잔액 확인, 구매 기록, 잔액 순위, 하루 한 번 출석 보상 |

| 관리자 | |
|---|---|
| `/자판기설치` | 버튼으로 쓰는 자판기 패널을 채널에 올림 (봇을 다시 켜도 버튼이 계속 동작) |
| `/설정 계좌` `/설정 로그채널` … | 입금 계좌, 로그 채널, 관리자 역할, 평생 회원 역할, 출석 보상, 최소 충전, 충전 보너스 % |
| `/상품 추가·수정·삭제·목록` | 상품 관리 |
| `/재고 추가·비우기` | 자동 전송 상품의 재고 (한 줄에 하나) |
| `/잔액관리 지급·차감` | 유저 잔액 직접 조정 |
| `/주문 완료·환불` | 주문 처리 / 환불 |
| `/입금 목록·연결·테스트` | 신청과 맞지 않은 입금 확인·수동 연결, 알림 문자 읽기 테스트 |
| `/평생 발급·지급·회수·목록` | 평생 무료 키 만들기, 키 없이 회원 지급, 회원 해제, 회원·남은 키 확인 |
| `/금고 잔액·출금·내역` | 충전으로 들어온 실제 돈 관리 (아래 참고) |

### 🤖 자동 처리 (세이브 자동 편집)

`editor/` 폴더에는 [Battle-Cats-Editor-Site-KR](https://github.com/books4jy-art/Battle-Cats-Editor-Site-KR)의
편집 코드(`worker.py`, `extras.py`)가 들어 있어요. 사이트에 접속하지 않고 **봇 서버에서 직접** 편집해요.

1. 구매자가 상품을 고르고 기종변경 코드·인증번호(필요하면 캐릭터 이름이나 장)를 입력해요.
2. 결제가 끝나면 봇이 세이브를 내려받아 편집하고 다시 올려요 (보통 1~3분, 한 번에 하나씩).
3. **새 이어하기 코드와 인증번호를 구매자에게 DM으로** 보내요. DM을 못 보내면 로그 채널에 코드가 올라와요.

결과별 처리:

| 상황 | 처리 |
|---|---|
| 성공 | 주문 완료, 새 코드 DM |
| 코드가 틀림 / 게임 서버 연결 실패 | 자동 환불 (입력한 코드는 그대로 쓸 수 있어요) |
| 세이브를 편집하지 못함 (지원하지 않는 게임 버전 등) | 자동 환불 + 바뀌지 않은 세이브의 새 코드 DM |
| 일부만 성공 | 새 코드 DM, 로그 채널에서 관리자가 `처리 완료`/`환불` 선택 |
| 코드는 사용됐는데 업로드 실패 | 🚨 관리자 알림 + 원본 세이브 백업 (`save-backups/`, 14일 보관) |

- 입력한 게임 코드는 로그 채널에 올라가지 않고, 처리가 끝나면 데이터베이스에서도 지워져요.
- 캐릭터 이름은 게임 데이터의 한국어 이름(모든 형태)으로 찾아요. 숫자 ID도 돼요.
- `통조림 50만개`는 게임 최대치(45,000개) 때문에 자동 처리가 안 돼서 관리자가 처리해요.
- 게임 버전은 `.env`의 `GAME_CC`(기본 `kr`)로 정해요.

### 냥코 서비스 상품 한 번에 등록

`/상품 기본목록`을 실행하면 `catalog.py`에 있는 상품 29개(28개는 자동 처리)(통조림·티켓·업그레이드 재화·스테이지·캐릭터·
전투 아이템·가마토토·골드회원)가 분류별로 등록돼요. 이미 등록된 상품은 가격은 그대로 두고
자동 처리 설정만 갱신해요. 가격·최대 수량은 `/상품 수정`으로 바꿀 수 있어요.

- **분류**: 상점에서 분류를 먼저 고르고, 그 안의 상품을 골라요.
- **단위별 상품** ("1개당", "200개당" 등): 구매할 때 수량을 입력하면 가격이 곱해져요.
- **주문 양식**: 구매할 때 기종변경(이어하기) 코드와 인증번호를 받고, "원하는 캐릭터" 상품은 캐릭터 이름도 받아요.
  관리자가 처리하는 상품은 입력한 내용이 관리자 로그 채널에만 올라가고, 주문을 `처리 완료`/`환불`하면
  로그와 기록에서 지워져요.
- **판매 시간**: "통조림 50만개"처럼 정해진 시간(한국 시간)에만 살 수 있게 할 수 있어요.

**상품 종류**
- **자동 전송** — 넣어 둔 재고(코드, 계정 등)를 구매 즉시 DM으로 보내요.
- **역할 지급** — 구매하면 역할을 줘요. (봇 역할이 그 역할보다 위에 있어야 해요)
- **관리자 처리** — 서비스 신청형. 로그 채널에 `처리 완료` / `환불` 버튼이 올라와요.
- **평생 무료 키** — 구매하면 `LIFE-XXXX-XXXX-XXXX` 키를 발급해요 (아래 참고).

### 평생 무료 키 (Free for life)

1. `/상품 추가 종류:평생 무료 키`로 상품을 만들어요. 가격은 자유롭게 (예: 50,000원).
2. 유저가 구매하면 새 키가 만들어져 DM으로 전송돼요.
3. 키를 `/키등록`(또는 자판기의 🔑 버튼)에 넣으면 **평생 무료 회원**이 되어 **모든 상품을 0원**으로 구매해요.
   - 키는 한 번만 쓸 수 있고, 다른 사람에게 **선물**할 수도 있어요.
   - 평생 무료 키 상품 자체는 회원도 정가로 사야 해요. (공짜 키를 무한으로 만들 수 없게)
   - `/설정 평생역할`을 정하면 회원에게 그 역할을 자동으로 줘요.
4. 키 주문을 환불하면 그 키는 사용 중지되고, 그 키로 등록한 회원도 해제돼요.
5. 관리자는 `/평생 발급`으로 이벤트용 키를 만들거나 `/평생 지급`으로 바로 회원을 만들 수 있어요.

## 계좌 자동 입금 확인은 어떻게 동작하나요?

한국 은행은 개인 계좌의 입금 내역을 볼 수 있는 API를 주지 않아요. (오픈뱅킹은 사업자 등록과 계약이 필요해요.)
그래서 이 봇은 **휴대폰에 오는 은행 입금 알림**을 사용해요.

1. 유저가 `/충전`으로 금액·입금자명을 신청해요.
2. 유저가 계좌로 입금하면 관리자 휴대폰에 은행 알림(문자/앱 푸시)이 와요.
3. 휴대폰의 알림 전달 앱이 그 알림을 봇의 웹훅 주소로 보내요.
4. 봇이 금액과 입금자명을 읽고 같은 신청을 찾아 **자동으로 잔액을 충전**하고 DM을 보내요.

- 신청보다 입금이 먼저 와도 괜찮아요. 신청할 때 자동으로 연결돼요.
- 맞는 신청이 없는 입금은 로그 채널에 올라오고, `/입금 연결`로 처리하면 돼요.
- 같은 알림이 두 번 와도 한 번만 충전돼요.
- 자동 확인이 안 되면 로그 채널의 `입금 확인 (승인)` 버튼으로 직접 승인할 수도 있어요.

### 휴대폰 설정 (안드로이드 예: MacroDroid)

1. MacroDroid 설치 → 매크로 추가
2. **트리거**: `알림 수신` (은행 앱 선택) 또는 `SMS 수신` (은행 번호), 내용에 `입금` 포함
3. **동작**: `HTTP 요청`
   - 방식: `POST`
   - 주소: `https://봇주소/deposit?token=WEBHOOK_SECRET값`
   - 본문: 알림 내용 (`[notification]` 또는 `[sms_message]`), Content-Type `text/plain`
4. 봇이 알림을 읽는지 먼저 `/입금 테스트 알림문자:(받은 문자 그대로)`로 확인해 보세요.

JSON으로 보내도 돼요: `{"amount": 10000, "name": "홍길동", "id": "알림마다 다른 값"}`
또는 `{"text": "알림 내용"}`. 헤더 `X-Webhook-Token`에 비밀번호를 넣어도 돼요.

KB·신한·농협·하나·우리·카카오뱅크·토스뱅크의 흔한 형식을 읽을 수 있어요. 읽지 못하는 형식이면
로그 채널에 `읽지 못한 입금 알림`이 올라오니, `.env`의 `DEPOSIT_REGEX`를 설정해 주세요.

> ⚠️ 웹훅 비밀번호(`WEBHOOK_SECRET`)가 새면 누구나 가짜 입금으로 잔액을 만들 수 있어요.
> 길고 무작위인 값을 쓰고 절대 공유하지 마세요.

## 금고 (실제 돈 관리)

실제 돈은 **봇이 아니라 입금 계좌에** 있어요. 봇은 그 돈을 장부로 관리해요.

- 충전이 승인될 때마다 입금된 금액(원)이 금고에 쌓여요.
- 관리자가 계좌에서 돈을 꺼냈다면 `/금고 출금 금액:50000 메모:10월 정산`으로 기록해요.
  금고에 있는 것보다 많이 출금할 수는 없고, 누가 언제 얼마를 꺼냈는지 로그 채널과 `/금고 내역`에 남아요.
- `/금고 잔액`으로 총 충전 금액, 출금한 금액, 지금 꺼낼 수 있는 금액을 확인해요.

## 설치

1. [디스코드 개발자 포털](https://discord.com/developers/applications)에서 앱 생성 → **Bot** → 토큰 복사
2. **OAuth2 → URL Generator**에서 `bot`, `applications.commands` 선택,
   권한은 `Send Messages`, `Embed Links`, `Manage Roles`(역할 상품을 쓸 때) → 생성된 링크로 서버에 초대
3. `.env.example`을 `.env`로 복사하고 값을 채워요.
4. 실행: `start.sh` (맥/리눅스) 또는 `start.bat` (윈도우), 또는 `python bot.py`
5. 서버에서 `/설정 로그채널`, `/설정 계좌` → `/상품 추가` → `/자판기설치`

### 호스팅

👉 **오라클 클라우드 무료 서버에 올리는 방법: [deploy/ORACLE.md](deploy/ORACLE.md)**

휴대폰에서 웹훅을 보낼 수 있도록 봇이 **인터넷에서 접속 가능한 주소**를 가져야 해요.
- 24시간 켜져 있는 VPS / 서버에서 실행하고 `WEBHOOK_PORT`를 열어 주세요.
- 집 PC에서 돌린다면 [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) 등으로 주소를 만들 수 있어요.
- 잠드는 무료 호스팅(Render 무료 등)은 입금 알림을 놓치고 데이터베이스(`shop.db`)가 지워질 수 있어서 추천하지 않아요.

`shop.db`에 잔액과 금고 기록이 모두 들어 있으니 주기적으로 백업해 주세요.
